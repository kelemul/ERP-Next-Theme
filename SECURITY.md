# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Active |

## Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public issue**. Instead:

- Email: kelemu3509@gmail.com
- Subject: "[HeliosDesk Security] Brief description"

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

This security policy covers the `helios_desk` app and its direct dependencies.
The underlying Frappe framework has its own security policy.
